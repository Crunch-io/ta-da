### **Crunch**

Search:

* Updated in-dataset search to remember your last view (Best Match or Folder) and use it by default.

AI Agent improvements:

* Connected the AI Agent to the Crunch MCP.
* Added the ability to change and remove weights in the AI Agent.
* Upgraded the AI Agent model to GPT-6 Luna.

Updated the Organization Settings panel interface.

Added a User Groups page for managing API scopes. See the [User Groups](https://help.crunch.io/hc/en-us/articles/49385053611533-User-Groups) helpdesk article.

Improved PowerPoint export functionality which allows to flexibly apply branding to downloads from Crunch.

### **Crunch Automation**

Updated the GRANT automation command to support MODERATOR permission. See the [GRANT Permissions command](https://help.crunch.io/hc/en-us/articles/11309275681037-GRANT-Permissions-command) helpdesk article.

Updated the REVOKE automation command to support MODERATOR permission. See the [REVOKE permissions command](https://help.crunch.io/hc/en-us/articles/11309360322829-REVOKE-Permissions-command) helpdesk article.

### **Backend/CrunchDB**

Removed all legacy team dataset shares from Crunch.
